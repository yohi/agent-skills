# Git Master (開発者向けガイド)

ソースコードの変更を分析し、論理的な変更単位ごとに分割されたアトミックなコミット（Atomic Commits）を作成し、日本語の Conventional Commits 形式でコミットメッセージを生成するスキルです。
エージェント向け指示は [SKILL.md](SKILL.md) を参照してください。

---

## 1. 主な特徴

- **日本語 Conventional Commits**: `feat: 新しいログインAPIの追加`, `fix: ...`, `docs: ...`, `refactor: ...` 等の接頭辞を付けた日本語メッセージを生成。
- **Atomic Commits (原子的コミット)**: 無関係な変更が1つのコミットに混ざるのを防ぎ、適切な粒度でファイルを分割ステージング。
- **一括追加の禁止**: `git add .` を禁止し、関連ファイルのみを個別にパス指定でステージング。
